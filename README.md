# Empresas Ativas RJ
Este projeto tem como objetivo processar os arquivos públicos disponibilizados pela Receita Federal para extrair as empresas do Brasil.

## Funcionalidades
- Carregamento e processamento de arquivos da Receita Federal
- Tratamento e limpeza de dados
- Junção de diferentes arquivos utilizando merge no pandas

## Tecnologias Utilizadas
- Python
- Pandas
- Streamlit
